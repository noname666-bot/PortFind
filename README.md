# PortFind

## Description
**PortFind** is a lightweight, fast, and efficient network diagnostic utility specifically designed and optimized for the **Termux** command-line environment on Android. In modern network environments, scanning and identifying active equipment quickly is crucial for system administrators, security enthusiasts, and developers. **PortFind** solves this by seamlessly combining host discovery mechanisms with targeted port scanning capabilities (powered natively by Nmap). This allows users to accurately map out local network topologies, pinpoint active services, and detect open ports on target devices with minimal overhead and maximum precision.

## Features
* **Rapid Host Discovery:** Quickly verifies whether a target IP address or host is alive and responding on the local network before executing heavier scans.
* **Targeted Port Scanning & Service Detection:** Automatically probes essential TCP/UDP ports to uncover running services, application banners, and underlying network configurations.
* **Optimized for Mobile Execution:** Built to run smoothly within a mobile terminal environment, giving you desktop-grade network diagnostic power directly from your smartphone or portable device.
* **Streamlined CLI Interface:** Features a clean, straightforward syntax designed for rapid execution without bloated menus or unnecessary parameters.

## Installation & Usage

git clone https://github.com/noname666-bot/PortFind.git
cd PortFind
cp PortFind ~/../usr/bin/
chmod +x ~/../usr/bin/PortFind
PortFind (THE_IP)
